# IUB Dance Club (IUBDNC) Website

Welcome to the official repository for the **IUB Dance Club (IUBDNC)** website. This project is a modern, responsive single-page web application built to showcase the energy, events, and dynamic community of the IUB Dance Club.

## 🚀 Features

- **Dynamic UI/UX**: Dark mode aesthetic with vibrant, youthful gradients (red, orange, purple).
- **Smooth Animations**: Intersection Observer-based scroll fade-ins and interactive hover effects.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop viewing.
- **Component-Based Architecture**: Built with React and Vite for blazing fast performance.
- **Team Directory**: Beautifully structured grid showcasing the Executive Body with their roles and contacts.

## 🛠️ Tech Stack

- **Frontend Framework**: [React](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)

## 🏃‍♂️ Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone git@github.com:Alvee011/IUBDNC.git
   cd IUBDNC
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.
